# ♻️ EcoSmart - Smart Waste Sorting App

**EcoSmart** is a clean and intuitive mobile application built with **Flutter** designed to simplify waste segregation, track personal recycling habits, and promote sustainable environmental practices. 

The application utilizes **SharedPreferences** for lightweight local data persistence, allowing users to save their sorting history, preferences, and reward points directly on their device without requiring a complex backend setup.

## 🚀 Key Features

* **Smart Waste Categorization:** Interactive guides and search tools to easily segregate household waste into Organic, Recyclable, Non-Recyclable.
* **Local Data Persistence:** Uses `shared_preferences` to safely store user progress, custom settings, and sorting statistics locally on the device.
* **Impact Tracker:** Visual counters showing personal environmental contributions, such as estimated plastic bottles saved and CO2 emissions reduced.
* **User-Friendly UI:** Designed using modern Material Design 3 guidelines for a smooth and accessible user experience across all devices.

---

## 🛠️ Tech Stack

* **Framework:** [Flutter](https://flutter.dev/) (Dart)
* **Local Storage:** [`shared_preferences`](https://pub.dev/packages/shared_preferences)
* **State Management:** Provider / `setState`
* **UI Components:** Material Design 3 & Custom Flutter Widgets
